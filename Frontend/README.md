# Voxel Ventures - MERN Stack E-Commerce
A full-stack e-commerce platform built to handle product management, secure user authentication, and order processing. 

## 🚀 Tech Stack
* **Frontend:** React.js
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Authentication:** JSON Web Tokens (JWT)

## ✨ Key Features
* **User Authentication:** Secure login and registration.
* **Product Browsing:** Filter, search, and view detailed product pages.
* **Shopping Cart:** Add, remove, and update item quantities.
* **Admin Dashboard:** A dedicated portal to manage inventory, update product details, and track orders.
